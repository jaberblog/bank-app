# Banking • Card Dashboard (Flutter)

پروژه فلاتر داشبورد بانکی (تمام‌عرض و واکنش‌گرا) همراه با تنظیمات خودکار **GitHub Actions** برای دریافت خروجی `APK` بدون نیاز به نصب فلاتر روی سیستم.

## روش دریافت خروجی APK در گیت‌هاب (GitHub Actions)

1. یک مخزن (Repository) جدید در GitHub بسازید.
2. محتویات داخل این فایل ZIP (پوشه‌های `lib`، `.github` و فایل‌های `pubspec.yaml` و غیره) را در مخزن خود آپلود یا Push کنید.
   - **نکته مهم هنگام آپلود دستی از طریق وب:** پوشه `.github` به دلیل شروع شدن با نقطه (`.`) در برخی فایل‌منیجرهای موبایل یا ویندوز مخفی (Hidden) است. مطمئن شوید گزینه نمایش فایل‌های مخفی روشن است تا پوشه `.github/workflows/build_apk.yml` هم آپلود شود.
3. پس از آپلود، در مخزن گیت‌هاب وارد تب **Actions** شوید.
4. ورک‌فلوی **Build Flutter Android APK** به صورت خودکار اجرا می‌شود (یا می‌توانید روی دکمه **Run workflow** بزنید).
5. پس از اتمام ساخت (حدود ۲ الی ۳ دقیقه)، وارد اجرای انجام‌شده شوید و از بخش پایین صفحه (**Artifacts**)، فایل **`banking-dashboard-release-apk`** را دانلود کنید.
